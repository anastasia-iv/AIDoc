# AIDoc ER

**Medical Entity Type Classification** - Проект посвящён задаче классификации медицинских сущностей по текстовому описанию.
На вход модели подаётся текстовое упоминание медицинского термина (например, название заболевания, препарата, процедуры), а на выходе модель предсказывает семантический тип сущности (например, Disease or Syndrome, Pharmacologic Substance, Diagnostic Procedure).

# Цель проекта

Цель проекта — разработать и обучить модель машинного обучения, которая:

- автоматически классифицирует медицинские сущности по семантическим типам;
- может быть дообучена на специализированных медицинских данных;
- обеспечивает базовое качество при умеренных вычислительных затратах;
- подходит для интеграции в пайплайны обработки медицинского текста.

## Набор данных

В проекте используется датасет **MedMentions (версия ST21pv)**.

Основные характеристики датасета:
- тексты аннотаций медицинских публикаций (PubMed);
- размеченные упоминания медицинских сущностей;
- 21 семантический тип сущностей (subset UMLS Semantic Types);
- выраженный дисбаланс классов.

Данные приводятся к формату задачи классификации текста:
- входные данные: текст сущности (опционально с контекстом);
- целевая переменная: семантический тип сущности.

## План экспериментов

### 1. Базовые эксперименты
- выбор лёгкой предобученной модели (например, `distilbert-base-uncased`);
- формулировка задачи как multi-class text classification;
- обучение модели на медицинском датасете без дополнительной оптимизации;
- получение базовых метрик качества для последующего сравнения.

### 2. Дообучение модели

- дообучение предобученной языковой модели на медицинском датасете;
- настройка гиперпараметров обучения через конфигурационный файл.

## Метрики

### Метрики качества модели

- **Accuracy** — доля корректно классифицированных сущностей;
- **Macro F1-score** — основная метрика качества, учитывающая дисбаланс классов.

### Технические метрики

- среднее время инференса;
- использование памяти и CPU;
- стабильность работы пайплайна обучения и инференса.

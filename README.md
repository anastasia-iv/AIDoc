# AIDoc ER

**Medical Entity Type Classification** - Проект посвящён задаче классификации медицинских сущностей по текстовому описанию.
На вход модели подаётся текстовое упоминание медицинского термина (например, название заболевания, препарата, процедуры), а на выходе модель предсказывает семантический тип сущности (например, Disease or Syndrome, Pharmacologic Substance, Diagnostic Procedure).

# Цель проекта

Цель проекта — разработать и обучить модель машинного обучения, которая:

- автоматически классифицирует медицинские сущности по семантическим типам;
- может быть дообучена на специализированных медицинских данных;
- обеспечивает базовое качество при умеренных вычислительных затратах;
- подходит для интеграции в пайплайны обработки медицинского текста.

**Бизнес-цель**

Автоматизировать структурирование медицинского текста (EHR/статьи/заметки врача/чаты), чтобы:

- ускорить разметку и индексирование,
- улучшить будущие downstream-задачи (граф знаний, RAG, поиск по симптомам/лекарствам/диагнозам),
- снизить ручную нагрузку на разметчиков/врачей.

## Набор данных

В проекте используется датасет **MedMentions (версия ST21pv)**.

Основные характеристики датасета:
- тексты аннотаций медицинских публикаций (PubMed);
- размеченные упоминания медицинских сущностей;
- 21 семантический тип сущностей (subset UMLS Semantic Types);
- выраженный дисбаланс классов.

Данные приводятся к формату задачи классификации текста:
- входные данные: текст сущности (опционально с контекстом);
- целевая переменная: семантический тип сущности.

## Метрики

### Метрики качества модели

- **Accuracy** — доля корректно классифицированных сущностей (целевое значение Accuracy ≥ 0.85);
- **Macro F1-score** — основная метрика качества, учитывающая дисбаланс классов(целевое значение Macro-F1 ≥ 0.80 (из-за дисбаланса классов важнее, чем accuracy)).

### Технические метрики

- среднее время инференса;
- использование памяти и CPU;
- стабильность работы пайплайна обучения и инференса.

**Целеве показатели**
- p95 latency ≤ 200 ms на CPU для 1 запроса (батч=1)
- память: ≤ 1.5 GB RAM (CPU-инференс)

# Результаты экспериментов

### Постановка эксперимента

В рамках **Task 2** был проведён базовый эксперимент по обучению модели
для задачи **классификации медицинских сущностей по семантическим типам**.

**Задача:**  
по текстовому упоминанию медицинской сущности (с опциональным контекстом из PubMed-аннотации)
предсказать её UMLS Semantic Type (подмножество ST21).

**Данные:**
- датасет: MedMentions (версия ST21pv);
- формат задачи: multi-class text classification;
- вход: `text + context`;
- выход: 1 из 21 семантического типа.

**Модель:**
- базовая модель: `cross-encoder/ms-marco-MiniLM-L-6-v2`;
- классификационная голова переинициализирована под 21 класс;
- обучение выполнялось с fine-tuning всей модели.

**Параметры обучения (основные):**
- число эпох: 2;
- batch size: 16;
- learning rate: 2e-5;
- max sequence length: 256;
- устройство: GPU (CUDA).
